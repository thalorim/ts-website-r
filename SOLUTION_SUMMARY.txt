================================================================================
  TEAMSPEAK WEBSITE - QUERY SPAM FIX - SOLUTION SUMMARY
================================================================================

PROBLEM IDENTIFIED:
Your website is sending TOO MANY queries to the TeamSpeak server, causing:
  • Query client spam in TS logs (RBot, thal1 connections/disconnections)
  • High server load
  • Potential connection issues

ROOT CAUSES:
  1. Cache expires too fast: 10 seconds (cache_serverinfo)
  2. JavaScript polls too often: every 10 seconds (status.js)
  3. Multiple tabs/users multiply the problem exponentially

CURRENT IMPACT:
  • 1 user with 1 tab = ~6 queries per minute
  • 10 users with 1 tab = ~60 queries per minute
  • 10 users with 2 tabs = ~120 queries per minute

================================================================================
  SOLUTION APPLIED
================================================================================

✓ FIXED: src/js/status.js
  - Changed polling from 10 seconds → 30 seconds
  - Reduces AJAX requests by 66%

⚠ TODO: Update database cache settings
  Run this SQL on your database:
  
    UPDATE config SET value = '30' WHERE identifier = 'cache_serverinfo';
    UPDATE config SET value = '30' WHERE identifier = 'cache_clientlist';

EXPECTED RESULTS AFTER BOTH FIXES:
  • 75-90% reduction in queries
  • 10 users = ~15 queries per minute (down from ~60)
  • Significantly less spam in TeamSpeak logs

Issue: Changes don't take effect
Fix: 1. Clear PHP opcache: service php-fpm reload

     3. Try incognito/private browsing mode
     4. Check file permissions on updated files
