Features Included:
================================================================================

✓ User's avatar image (from profile or default icon)
✓ Username in large bold text
✓ Online/Offline status with color coding
  - Green (✓) when ONLINE
  - Red (✗) when OFFLINE
✓ Clickable profile link
✓ Server group icon and name
✓ Social media links with emojis
✓ Profile bio/description (truncated to 200 chars)
✓ Centered alignment
✓ BBCode formatting

================================================================================
How to Test:
================================================================================

1. Run the bot:
   cd /var/www/web.reape.rs
   php src/private/php/status-display-bot.php --once

2. Open TeamSpeak client

3. Navigate to channel 251746 (or your configured channel)

4. Right-click channel → Channel Info → View Description

5. You should see the formatted status display!

================================================================================
Customization:
================================================================================

To customize the appearance, edit:
  src/private/php/Utils/StatusDisplayManager.php
  
Look for the buildChannelDescription() method around line 150

You can modify:
- BBCode formatting
- Font sizes
- Colors
- Layout
- What information is displayed
- Order of elements
