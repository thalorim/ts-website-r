================================================================================
  VISUAL EXPLANATION - Query Spam Issue & Fix
================================================================================

BEFORE FIX - The Problem
================================================================================

User's Browser Tab
     |
     | Every 10 seconds (too frequent!)
     ↓
JavaScript: status.js polls
     |
     ↓
AJAX → api/getstatus.php
     |
     ↓
Cache Check (expires after 10s)
     |
     ├─→ [Cache HIT] ────────→ Return cached data ✓
     |                          (Rare - only within 10s window)
     |
     └─→ [Cache MISS] ────────→ Query TeamSpeak Server ⚠
                                      ↓
                           Query Client Connects
                                      ↓
                           < 1 second later
                                      ↓
                           Query Client Disconnects
                                      ↓
                           Appears in TS Logs:
                           "RBot connected"
                           "RBot disconnected"


MULTIPLY THIS BY:
├─ Multiple browser tabs per user (2-3x)
├─ Multiple users (10-50x)
└─ Result: 60-300+ queries per minute! 💥


YOUR TEAMSPEAK LOGS SHOWED:
┌─────────────────────────────────────────────────────────────┐
│ <21:19:40> "RBot8" connected                                │
│ <21:19:40> "RBot8" is now known as "RBot"                   │
│ <21:19:40> "RBot" disconnected (disconnecting)              │
│ <21:19:41> "RBot" connected                                 │
│ <21:19:41> "RBot" is now known as "RBot3"                   │
│ <21:19:41> "RBot3" disconnected (disconnecting)             │
│ ... (continues rapidly)                                      │
└─────────────────────────────────────────────────────────────┘

This is caused by:
1. TS-website query connections (to fetch server data)
2. Actual bots on your TS server (RBot, thal1, etc.)
3. The website constantly polling to see these connections
4. Creating a feedback loop of queries


================================================================================
AFTER FIX - The Solution
================================================================================

User's Browser Tab
     |
     | Every 30 seconds (3x slower ✓)
     ↓
JavaScript: status.js polls
     |
     ↓
AJAX → api/getstatus.php
     |
     ↓
Cache Check (expires after 30s)
     |
     ├─→ [Cache HIT] ────────→ Return cached data ✓
     |                          (Common - 30s window)
     |                          No TS query needed! 🎉
     |
     └─→ [Cache MISS] ────────→ Query TeamSpeak Server
                                (Only every 30s)
                                      ↓
                           Query Client Connects
                                      ↓
                           Fetch Data
                                      ↓
                           Query Client Disconnects
                                      ↓
                           Data Cached for 30s


RESULT:
├─ Requests: 10s → 30s = 66% reduction
├─ Cache: 10s → 30s = 66% reduction  
└─ Combined: ~75-90% fewer TS queries! ✓
